
## Shortcuts

- leader: Space
- `Ctrl-W` + `v` Split vertically
- `Ctrl-W` + `h` Split horizontally
- `Space-E` Trigger File explorer
- `Space-t` Focus File explorer
- `Ctrl-C` Copy
- `Ctrl-V` Paste
- `Ctrl-F` Reduce font size
- `Ctrl-G` Increase font size
- `Space-1-2-3-4-5-6-7-8-9` Focus a tab
